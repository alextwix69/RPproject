# Tasks 26.05: registration entrypoint, main menu callbacks и подготовка lobby flow

Дата: 2026-05-26

## Цель дня

Довести основу Telegram-бота до состояния, где:

- `/start` сохраняет или обновляет Telegram-пользователя;
- главное меню работает через inline-кнопки, а не reply-клавиатуру;
- callbacks `main:*` обрабатываются через отдельный router;
- кнопка регистрации становится реальной точкой входа в следующий registration/lobby flow;
- тесты проверяют ключевые контракты до ручной проверки в Telegram.

## Общий контракт

Callback-data главного меню:

- `main:register` - вход в регистрацию;
- `main:profile` - профиль пользователя;
- `main:lobby` - будущий список/экран лобби;
- `main:help` - помощь;
- неизвестный `main:*` - fallback.

Intent names:

- `REGISTER`
- `PROFILE`
- `LOBBY`
- `HELP`
- `UNKNOWN`

Тексты лучше держать рядом с callback-router, например в `src/callbacks/main_menu.py`, пока проект маленький.
